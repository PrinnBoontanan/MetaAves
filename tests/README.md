# MetaAves automated game-system test\n\nThe end-to-end test uses the real MetaAves page in Chromium and runs multiple complete rounds.\n\n## Run locally\n\nStart MetaAves at the normal local URL first (the project currently uses Live Server on port 8080), then:\n\n    npm install\n    npx playwright install chromium\n    npm run test:game\n\nBy default it runs 20 games. To change the number:\n\n    METAAVES_GAMES=25 npm run test:game\n\nTo use another local URL:\n\n    METAAVES_BASE_URL=http://localhost:8080 npm run test:game\n\n## What it checks\n\n- Complete bird/taxonomy database integrity.\n- Duplicate gameplay common names and scientific names.\n- Every species has a valid taxonomy chain back to Aves.\n- Taxonomy parent cycles and missing parents.\n- Every configured order/family clade path follows its actual parent chain.\n- Generated species clade membership follows actual clade parents.\n- World and Thailand game pools when Thailand data is available.\n- 12-guess starting state.\n- Invalid guesses do not consume a guess.\n- Duplicate guesses do not consume a guess.\n- Real guesses consume exactly one guess and are recorded.\n- Correct guesses produce a win.\n- 12 wrong guesses produce a loss.\n- The rendered taxonomy tree contains every node produced by the game's real tree model and has no duplicate node IDs.\n- The final study card contains the mystery bird's order, family, genus, and scientific name.\n- Browser/page errors are collected and fail the test.\n\nThe test writes an HTML report to `playwright-report/` when it finishes; both `playwright-report/` and `test-results/` are local-only generated output and are ignored by Git.
